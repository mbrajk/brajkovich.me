I have been on a spree of learning to use the command line more effectively and somewhere along the way I realized something: I am *really* tired of looking at the same terminal background every day.

So I did what any reasonable person would do. I wrote a script to fix it.

![Windows Terminal with a randomized background — the "joker" profile showing dotnet CLI output with a custom background image at partial opacity](/assets/blog/20260105/terminal-bg-demo.png)

## What It Does

The [Windows Terminal Background Randomizer](https://gist.github.com/mbrajk/af494f63178ffda30f3e0dd47d58d9e4) is a PowerShell script that randomly picks an image from a directory and sets it as the background for any Windows Terminal profile. Every time you open a new terminal — fresh vibes.

Here's the short list of what it handles:

- **Random background selection** — recursively scans a folder for images (`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`) and picks one at random. It also excludes the current background so you're always getting something new.
- **Per-profile support** — target any Windows Terminal profile by name. Want your PowerShell tab to have a different aesthetic than your WSL tab? Done.
- **Custom opacity** — prefix any filename with brackets like `[75]image.png` to control background opacity on a per-image basis. Default is 40% if you don't specify anything.
- **Animated backgrounds** — pass the `anim` flag and it'll source `.gif` files so your terminal can really come alive. Subtle, tasteful, probably distracting. Worth it.

## Filtering by Theme with Filename Metadata

This is the part that got a little unhinged in the best way.

I wanted to be able to filter images by mood — like "give me something that looks like a hacking scene" or "I want pink today." But I didn't want to set up a database or metadata file for what is essentially a folder of wallpapers.

So I built a convention into the filenames themselves. Something like:

```
+pink+hacker+neon+.jpg
+calm+nature+green+.jpg
+dark+cyberpunk+.jpg
```

The `+` delimiters act as tags baked right into the filename. When you filter on a theme or color, the script searches for filenames containing that tag and randomly picks from the matches. Still random — just scoped.

Is it a substitute for a real tagging system or a proper media library? Absolutely not. But for a personal collection of a few hundred wallpapers, it's surprisingly effective. You can extend it with any metadata you want — just add another `+tag+` to the filename. No config files, no setup, no dependencies. It just works.

## How to Use It

Grab the script from the [gist](https://gist.github.com/mbrajk/af494f63178ffda30f3e0dd47d58d9e4) and run it like this:

```powershell
# Randomize a profile's background from a folder
.\Set-TerminalBackground.ps1 -profileName "PowerShell" -imagesPath "~/Pictures/Terminals"

# Clear a profile's background
.\Set-TerminalBackground.ps1 -profileName "PowerShell" -imagesPath ""

# Set a specific image
.\Set-TerminalBackground.ps1 -profileName "PowerShell" -imagesPath "~/Pictures/specific.png"
```

I run this on terminal startup so every session is a surprise. You could also hook it into a scheduled task if you want your backgrounds rotating even when you're not opening new tabs.
